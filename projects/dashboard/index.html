🚀 Project Overview#

This is a modern admin dashboard built with Next.js (App Router) and shadcn/ui.

The goal of this project was to practice:

  • Layout architecture in Next.js
  • Dark / Light theme toggle
  • Reusable UI components
  • Clean dashboard design

🛠 Tech Stack#

  • Next.js
  • TypeScript
  • TailwindCSS
  • shadcn/ui
